# Git Basics: course storyboard

A 10-slide e-learning storyboard that introduces Git, version control and
branching strategies to new developers.

## What it covers

| Slide | Content |
| --- | --- |
| 1 to 2 | Title and course overview, with learning objectives |
| 3 | What Git is, with a diagram of branches and version tags |
| 4 to 5 | Version control systems, repositories and working copies, shown as a push, pull, commit and update flow |
| 6 to 7 | Branching and the four common branching strategies |
| 8 to 9 | Two knowledge checks: a drag-and-drop matching activity and a multiple-choice question |
| 10 | Key takeaways |

## How the course is built

- It opens with **objectives** that say what the learner will be able to do.
- Each concept has **one idea per slide**, with a diagram next to short bullets.
- **Knowledge checks** use two different interaction types so learners practise recall and recognition.
- It closes with **key takeaways** that restate each concept in one sentence.
