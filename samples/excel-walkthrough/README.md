# Excel 365 walkthrough

A step-by-step, screenshot-led walkthrough that teaches learners to perform
data calculations with formulas in Microsoft Excel 365.

## What it covers

| Practice area | Functions and features |
| --- | --- |
| Simple calculations and running totals | Cell references, `SUM`, fill handle |
| Counting cells in a range | `COUNT`, `COUNTBLANK`, `COUNTIF` |
| Built-in functions | `IFS`, `SWITCH`, `AVERAGEIFS`, `MAXIFS`, `QUOTIENT`, `MOD` |
| Default formula options | R1C1 reference style, Formula AutoComplete |

## How the guide is built

- It opens with **the exercise**: the tasks the learner will complete, so they know the goal before they start.
- Each practice area then has **numbered steps**, one action per step, with the exact formula to type and the cell where the result appears.
- Every step with a result has an **annotated screenshot**, and every screenshot has descriptive alt text for readers who use screen readers.
- Reference tables explain the rules behind a formula, such as the gift amount thresholds used in `IFS`.
