# Setting up your workspace

Follow these steps to prepare your workspace before your first day. The whole
setup takes about ten minutes, and you only need to do it once.

## Install the tools

Install Python from the official website, then check that it works:

```bash
python3 --version
```

You should see a version number such as `Python 3.12.4`. If you see an error
instead, restart your terminal and try again.

## Create your project folder

Create a folder for your work and open it in your editor. Keep all of your
files for this project in this folder so that they are easy to find later.
